Midia Queries

Midia Queries são usadas para criar layouts responsivos, ou seja,
layouts que se adaptam a diferentes tamanhos de tela.

As midia queries são usadas para aplicar estilos diferentes dependendo
do tamanho da tela do dispositivo.

A sintaxe das midia queries é a seguinte:

            @media (condição) {
                /* estilos */
            }

A condição pode ser baseada em diferentes características do
dispositivo, como largura da tela, altura da tela, orientação,
resolução, entre outras.

Exemplo de midia query para aplicar estilos diferentes em telas menores
que 600px: 

            @media (max-width: 600px) {
                /* estilos para telas menores que 600px */
            }
        
        📱 Celular  | até 600px         
        📱 Tablet   | 601px até 1024px  
        💻 Notebook | 1025px até 1440px 
        🖥️ Desktop  | 1441px+

ela funciona no efeito cascata, entao voce so muda o que realmente for
mudar, não precisa reescrever o CSS inteiro.
