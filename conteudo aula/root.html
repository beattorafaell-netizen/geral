Root, var()

Root

A propriedade :root é um seletor que define variáveis CSS no nível raiz do documento. Ele cria as variaveis globais para o css.

                :root {
                    --cor-principal: #3498db;
                    --cor-fundo: #111;
                    --tamanho-titulo: 32px;
                    --tamanho-texto: 16px;
                }

O nome que dara a uma propriedade CSS é o da direira e a propriedade em si é o da esquerda, apos o sinal de igualdade.

var()

A função var() é usada para acessar o valor de uma variável CSS definida com :root.

                .elemento {
                    background-color: var(--cor-principal);
                    color: var(--cor-fundo);
                    font-size: var(--tamanho-titulo);
                }

A função var() permite reutilizar valores de variáveis CSS em diferentes partes do estilo, facilitando a manutenção e atualização do design.

É apenas usar o var() e o nome que você nomeou em ":root"
